# Movie Recommendation System

A content-based movie recommendation system built using Python and the TMDB 5000 Movies dataset.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Jupyter Notebook

## Project Features
- Movie data preprocessing
- Content-based recommendation
- Movie similarity analysis

## Dataset
The project uses the TMDB 5000 Movies and Credits datasets. Both datasets are included as ZIP files in this repository.

## How to Run
1. Download or clone this repository.
2. Extract both dataset ZIP files.
3. Install the required Python libraries.
4. Open `MovieRecommender.ipynb` in Jupyter Notebook.
5. Run the notebook cells in order.
